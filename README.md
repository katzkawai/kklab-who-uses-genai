# 誰が、何のために生成AIを使っているか

日本と主要国について、生成AIを**誰が**、**何のために**使っているかを、公式統計と一次調査だけで見える化した GitHub Pages です。

**公開ページ:** https://katzkawai.github.io/who-uses-genai/

## 何が載っているか

- **誰が:** 年齢・学歴・性別・人種。年齢が最も効く。
- **何に:** 情報理解、文章、学習、仕事、私生活。ChatGPTの実会話では仕事は約3割。
- **どの国が:** Microsoft の同一物差し（15–64歳の期間利用率）で147経済を順位付け。日本は2026 Q1で 22.5%、48位。

同じ「利用率」でも定義が違う数値は、同じ図に載せていません。

## 出典

| 系列 | 定義 | 出典 |
| --- | --- | --- |
| 日・米・独・中の経験率 | 15–69歳、生涯経験 | 総務省 令和8年版情報通信白書（2026年1–2月調査） |
| 欧州 | 16–74歳、直近3か月 | Eurostat `isoc_ai_iaiu` 2025 |
| 米国の属性・用途 | 成人の確率標本 | Pew Research Center 2025–2026 |
| 国別順位 | 15–64歳がその期間に生成AIを使った推計 | Microsoft AI Diffusion / Our World in Data |
| 会話の中身 | ChatGPT消費者プランの実会話 | OpenAI / NBER W34255 |
| 所得グループ | ChatGPT、ネット利用者比 | World Bank PRWP 11231 |

再配布用データ: [`data/dataset.json`](data/dataset.json)

## ローカルで見る

```bash
python3 -m http.server 8080
```

http://localhost:8080 を開く。

## 注意

総務省調査はインターネットパネルで、Pew や Eurostat の無作為抽出より高く出ます。Microsoft はテレメトリのモデル推計です。企業の業務利用率（日本 86%）は個人の数字ではありません。
